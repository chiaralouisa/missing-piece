Background

Comprehensive genomic profiling is central to precision oncology, but panel gene coverage differs widely across institutions and health systems.

Smaller targeted panels cut cost and turnaround time, yet leave part of the tumour genomic profile unmeasured — and therefore invisible to treatment decisions.

Question. Can a conditional generative model reconstruct the missing portion of a large panel from a smaller, routinely available one?

The completion task

Cohort

  • Non-small cell lung cancer, MSK-CHORD, MSK-IMPACT sequencing
  • Only patients sequenced on a panel covering the 164 target genes — otherwise absent calls are missing data, not wild-type
  • One sample per patient, so repeat samples cannot straddle a split
  • Alterations encoded as binary events: non-synonymous mutations and copy-number alterations

Model

Conditional flow matching

A conditional generative framework learns the joint distribution of the 164 unobserved genes given the observed 341-gene profile, rather than 164 independent classifiers.

  • Continuous variant — velocity field regressed along a straight-line path from noise to the binary profile
  • Discrete variant — flow matching directly on {0, 1, MASK}; at t = 0 every gene is masked, so one forward pass yields exact conditional marginals with no sampling noise

Because the model is generative, it produces coherent whole profiles — preserving co-occurrence and mutual exclusivity — not just per-gene probabilities.

Protocol

  • Patient-level split, stratified on observed-panel burden: 70 / 15 / 15 confirm split
  • AUROC as primary metric, computed per gene then averaged
  • Bootstrap confidence intervals resampled at patient level
  • Permutation test for patient-specific information
Confirm the split actually used — the abstract's 75/15/15 sums to 105%.

Why the averaging matters

At 1.21% prevalence, how AUROC is averaged decides what it means.

  • Pooled — all gene–patient pairs ranked together. Dominated by prevalence differences between genes.
  • Per-gene (macro) — AUROC within each gene, then averaged. A patient-blind model scores exactly 0.500, so any lift is patient-specific.

We therefore report macro AUROC, and benchmark against a burden-only model as well as a prevalence-only baseline.

Limitations

  • The small-panel input is a retrospective mask on large-panel data, not output from a genuinely 341-gene assay
  • Single-institution cohort; external validation not yet performed
  • At 1.21% prevalence, positive predictive value is low at any usable sensitivity — AUROC is not a decision metric
  • Predictions are not a substitute for sequencing and must not gate therapy

Conclusions

  • Generative flow models recover clinically relevant genomic information from smaller targeted panels
  • Broader tumour genomic profiles can be partially reconstructed from routinely available panel data
  • Plausible use is triage — flagging tumours that warrant reflex broad sequencing — potentially broadening access to comprehensive profiling
